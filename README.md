# Домашнее задание: параллельные вычисления

**Номер:** 7  
**Автор:** Гаврилина Алёна Дмитриевна

## Вариант

- **Задача:** найти первый элемент, который больше заданного числа.
- **Параллелизация:** `atomic` — общий счётчик.
- **Тип данных:** `int` (32 бита).

## Файлы

- `main.cpp` — программа с последовательной и параллельной версиями.
- `Makefile` — сборка и запуск программы.
- `README.md` — описание проекта.

## Сборка и запуск

Для сборки и запуска всех версий выполни:

```bash
make full
```

Программа запустит три версии:
- последовательную;
- параллельную с 4 потоками;
- параллельную с 8 потоками.

Также доступны команды:

```bash
make serial
make parallel4
make parallel8
make clean
```

## Как работает программа

1. Создаёт массив из 10 миллионов случайных чисел от 0 до 1 000 000.
2. Использует генератор с фиксированным seed `42`, поэтому числа при каждом запуске одинаковые.
3. Находит первый элемент, который больше `999990`.
4. Выводит индекс найденного элемента, его значение и время поиска.

## Параллельные вычисления

Для работы потоков используется `std::atomic`.

- **`next_block`** — общий счётчик, который распределяет между потоками блоки по 100 000 элементов.
- **`first_idx`** — хранит индекс первого подходящего элемента.
- Потоки работают с разными блоками массива.
- Если найденный индекс уже меньше начала блока, поток может завершить работу.
- Результат параллельной версии совпадает с последовательной.

## Время работы

Подходящий элемент обычно находится достаточно близко к началу массива, поэтому поиск занимает мало времени.

Параллельная версия не всегда работает быстрее последовательной, поскольку создание потоков тоже требует времени.
